## 02-2 문자열 자료형
<b>파이썬 문자열의 특징</b>
-  값이 한 번 할당 되면 변경 불가능한 <b>immutable 자료형</b>이다. 따라서 할당된 문자열 값의 요소를 바꿀 수 없다.


### [1] 문자열 만드는법
- 큰따옴표로 양쪽 둘러싸기
- 작은 따옴표로 양쪽 둘러싸기
- 큰따옴표 3개를 연속으로 써서 양쪽 둘러싸기 -> 여러줄 입력에 대한 줄바꿈도 반영 해준다.
- 작은따옴표 3개를 연속으로 써서 양족 둘러싸기 -> 여러줄 입력에 대한 줄바꿈도 반영 해준다.

### [2] 문자열의 연산
- 피연산자 문자열에 대해서 `+`로 연결이 가능하다.
- 문자열에 `*`를 이용해서 문자열의 곱셈이 가능하다.
- 문자열을 저장한 a 변수가 있을 때 <b>문자열 길이</b>는`len(a)` 함수를 이용한다.
- 문자열은 인덱싱과 슬라이싱이 가능하다.<sup>[설명](#02-2-2:1)</sup>

#### (1) <span id="02-2-2:1">문자열은 인덱싱과 슬라이싱이 가능하다.</span> (<a href="https://wikidocs.net/13" target="_blank">참고자료</a>)
인덱싱은 무엇인가를 가리키는 것을 말하며, 슬라이싱은 무엇인가를 잘라 내는 것을 말한다.

<br/>

```python
a = "Life is too short, You need Python"
```
문자열 인덱싱은 문자열의 인덱스 값을 통해 문자의 요소에 접근하는 것을 말한다. (`a[0]`, `a[3]`)
- 인덱싱에는 음수 인덱스가 들어갈 수 있으며 이는 뒤에서부터 센다. (맨 뒤의 요소는 `-1`부터 시작)

문자열 슬라이싱은 주어진 문자열의 범위를 지정하여 문자를 뽑아내는 것을 말한다.
- 예를 들어 `k = a[0:4]`라고 한다면 <b>Life</b>의 결과값을 얻어낼 수 있다.
- 시작번호가 생략되면 지정된 끝 번호까지의 문자열을 뽑아낸다. 반대도 마찬가지이다.
- 시작번호와 끝 번호가 생략된다면 문자열 전체를 반환한다.
- 인덱싱과 마찬가지로 슬라이싱의 범위는 음수가 가능하며 맨 뒤의 요소는 `-1`부터 시작한다.

### [3] 포매팅(<a href="https://wikidocs.net/13" target="_blank">참고자료</a>)
#### [3-1] 문자열 포매팅: 포맷 코드를 이용한 문자열 포매팅
🌱 [배경지식] 문자열 포맷 코드

|코드|설명|
|---|---|
|%s|문자열(String)|
|%c|문자 1개(character)|
|%d|정수(Integer)|
|%f|부동소수(floating-point)|
|%o|8진수|
|%x|16진수|
|%%|Literal %(문자 `%`자체)

<br/>

🧑🏻‍💻[예제 코드]: 문자열 포매팅의 기초 코드
```python
number = 3
"I eat %d apples." % number     # I eat 3 apples.
"I eat %d apples." % 3          # I eat 3 apples.
"I eat %s apples." % "five"     # I eat five apples.
"rate is %s" % 3.234            # rate is 3.234
"Error is %d%%." % 98           # Error is 98%.
```
<br/>

🧑🏻‍💻[예제 코드]: 문자열 포매팅의 정렬
```python
"%10s" % "hi"             #        hi
"%-10sjane." % 'hi'       # hi        jane.
```
파이썬은 포맷코드의 가운데에 정수(10,-10)를 넣으면 대입되어지는 문자를 정렬해준다.
- 포맷코드 가운데 값이 <b>양수</b>라면, 양수 만큼 좌측에 공백이 생긴다. 문서 관점에서는 우측 정렬이다.
- 포맷코드 가운데 값이 <b>음수</b>라면, 음수의 절대값 만큼 우측에 공백이 생긴다. 문서 관점에서는 왼쪽 정렬이다.

<br/>

🧑🏻‍💻[예제 코드]: 문자열 포매팅을 이용한 소수점 표현
```python
"%0.4f" % 3.42134234             # 3.4213
"%.4f" % 3.42134234              # 3.4213
"%10.4f" % 3.42134234            #     3.4213
```
주어진 실수 값에 대하여 특정 소수점 만큼 표현하는 경우가 있을 수 있다.
이때는 포맷코드의 가운데에 소수점을 넣어 자릿수 표현 범위를 지정해준다.

더불어서 소수점의 정수 표현부에 양수 값을 넣어주게 되면 전체 길이가 지정된다.
`"%10.4f" % 3.42134234`의 경우는 총 10개의 길이가 되므로 앞에 공백이 4개가 있는 결과가 나온다.

#### [3-2] format 함수를 사용한 포매팅
🧑🏻‍💻[예제 코드]: format함수의 포매팅 기초 (옛날 방식)
```python
# 기본 사용
number = 3
"I eat {0} apples".format(number)       # I eat 3 apples
"I eat {0} apples".format(3)            # I eat 3 apples
"I eat {0} apples".format("five")       # I eat five apples

# 두 개 이상의 값 포매팅
number = 10
day = "three"
"I ate {0} apples. so I was sick for {1} days.".format(number, day)              # I ate 10 apples. so I was sick for three days.
"I ate {number} apples. so I was sick for {day} days.".format(number=10, day=3)  # I ate 10 apples. so I was sick for 3 days.
"I ate {0} apples. so I was sick for {day} days.".format(10, day=3)              # I ate 10 apples. so I was sick for 3 days.

# 정렬
"{0:<10}".format("hi")   # hi        
"{0:>10}".format("hi")   #         hi
"{0:^10}".format("hi")   #    hi    

# 공백채우기
"{0:=^10}".format("hi")  # ====hi====
"{0:!<10}".format("hi")  # hi!!!!!!!!

# 소수점 표현
y = 3.42134234
"{0:0.4f}".format(y)    # 3.4213
"{0:10.4f}".format(y)   #     3.4213

# { 또는 }를 문자 그 자체로 출력하기 (두 개 사용한다.)
"{{ and }}".format()    # { and }
```

<br/>

🔥 🧑🏻‍💻[예제 코드]: format함수의 포매팅 기초 (최근 방식)
```python
# 기본 사용 방법
name = '홍길동'
age = 30
f'나의 이름은 {name}입니다. 나이는 {age}입니다.'               # 나의 이름은 홍길동입니다. 나이는 30입니다.

age = 30
f'나는 내년이면 {age + 1}살이 된다.'                         # 나는 내년이면 31살이 된다.

d = {'name':'홍길동', 'age':30}
f'나의 이름은 {d["name"]}입니다. 나이는 {d["age"]}입니다.'     # 나의 이름은 홍길동입니다. 나이는 30입니다.

# 정렬
f'{"hi":<10}'  # hi
f'{"hi":>10}'  #         hi
f'{"hi":^10}'  #     hi    

# 공백 채우기
f'{"hi":=^10}'  # ====hi====
f'{"hi":!<10}'  # hi!!!!!!!!

# 소수점의 표현
y = 3.42134234
f'{y:0.4f}'     # 3.4213
f'{y:10.4f}'    #     3.4213

# { 또는 }를 문자 그 자체로 출력하기 (두 개 사용한다.)
f'{{ and }}'    # { and }

# 금액에 콤마(,) 삽입
 f"난 {1500000:,}원이 필요해"  # 난 1,500,000원이 필요해'
```

### 🔥 [4] 문자열 관련 함수
- count('a'): 문자열 중 문자 a의 총 개수값을 세어 반환한다.
- find('a'): 문자열 중 문자 a가 처음으로 나온 위치를 반환한다. 만약 찾는 문자나 문자열이 없다면 -1을 반환한다.
- index('a'): 문자열 중 문자 a가 처음으로 나온 위치를 반환한다. 만약 찾는 문자나 문자열이 없다면 오류가 발생한다.
- join('abc'): `',''.join("abc")`라고 한다면 결과는 `a,b,c`이다. (리스트, 튜플 입력으로도 사용 가능)
- upper(): 소문자를 대문자로 바꾼다. 만약 문자열이 이미 대문자라면 아무런 변화가 없다.
- lower(): 대문자를 소문자로 바꾼다. 만약 문자열이 이미 소문자라면 아무런 변화가 없다.
- rstrip(): 문자열의 오른쪽 공백을 지운다.
- lstrip(): 문자열의 왼쪽 공백을 지운다.
- strip(): 문자열의 양쪽 공백을 지운다.
- replace('old', 'new'): 문자열 안의 특정한 값을 다른 값으로 치환한다.
- split(): 
    ```python
    a = "Life is too short"
    a.split()  # ['Life', 'is', 'too', 'short']

    b = "a:b:c:d"
    b.split(':') # ['a', 'b', 'c', 'd']
    ```
     <b>문자열을 나누어주는 함수</b>이다. <b>반환값은 리스트</b>이며 <u>인자로 문자를 넣어주면 해당 문자를 기준으로 값을 나눈다.</u>

- isalpha(): 문자열이 알파벳으로 구성되어 있는지 확인한다. 반환 값은 boolean 값이다.
- isdigit(): 문자열이 숫자로만 구성되어 있는지 확인한다. 반환 값은 boolean 값이다.
- startswith("abc"): 문자열이 특정 문자(열)로 시작하는지 확인한다. 반환 값은 boolean 값이다.
- endwith("abc"): 문자열이 특정 문자(열)로 시작하는지 확인한다. 반환 값은 boolean 값이다.

## 🔥 02-3 리스트 자료형
🧑🏻‍💻[예제 코드]: 리스트의 생성 예제
```python
odd = [1,3,5,7,9]
a = []
b = [1, 2, 3]
c = ['Life', 'is', 'too', 'short']
```
리스트는 `리스트명 = [요소1, 요소2, 요소3, ...]`으로 만든다. 
또한 비어있는 리스트는 `a = list()`로 생성이 가능하다. 

<br/>

```python
d = [1, 2, 'Life', 'is']
e = [1, 2, ['Life', 'is']]
```
파이썬의 리스트는 여러 자료형 요소가 혼합된 형태일 수 있으며 리스트 자체를 요소값으로 가질 수 있다.

### [1] 리스트의 인덱싱과 슬라이싱
#### [1-1] 리스트의 인덱싱
```python
a = [1, 2, ['a', 'b', 'c'], 3]

# 리스트의 인덱싱
a[0]      # 1
a[1]      # 2
a[2]      # ['a', 'b', 'c']
a[2][0]   # a
a[2][-1]  # c
a[3]      # 3
a[-1]     # 3

# 리스트의 슬라이싱

```
리스트도 문자열처럼 인덱싱과 슬라이싱이 가능하다. 
예시에는 포함하지 않았지만 `[1, 2, ['a', 'b', ['Life', 'is']]]`형태의 리스트도 가능하다.

<br/>

#### [1-2] 리스트의 슬라이싱
```python
a = [1, 2, 3, 4, 5]
a[0:2]     # [1, 2]
a[:2]      # [1, 2]
a[2:]      # [3, 4, 5]

b = [1, 2, 3, ['a', 'b', 'c'], 4, 5]
a[2:5]     # [3, ['a', 'b', 'c'], 4]
a[3][:2]   # ['a', 'b']
```

### [2] 리스트의 연산
- +: 리스트 더하기 <sup> [내용정리](#02-3-2:1) </sup>
- *: 리스트 반복하기 <sup> [내용정리](#02-3-2:2) </sup>
- len(list): 리스트의 길이는 len으로 구한다.
- 리스트의 수정과 삭제가 가능하다. <sup> [내용정리](#02-3-2:3) </sup>

#### <span id="02-3-2:1">[2-1] 리스트 더하기</span>
```python
a = [1, 2, 3]
b = [4, 5, 6]

a + b   # [1, 2, 3, 4, 5, 6]
```

#### <span id="02-3-2:2">[2-2] 리스트 반복하기</span>
```python
a = [1, 2, 3]
a * 3 # [1, 2, 3, 1, 2, 3, 1, 2, 3] 
```

#### <span id="02-3-2:3">[2-3] 리스트의 값 수정과 삭제 </span>
```python
# 리스트의 수정
a = [1, 2, 3]
a[2] = 4
a    # [1, 2, 4]

# 리스트의 삭제
a = [1, 2, 3, 4, 5, 6 ,7]
del a[2]
a   # [1, 2, 4, 5, 6, 7]
del a[2:]
a  # [1, 2]
```
리스트 값의 수정은 리스트의 인덱싱을 통해 변경이 가능하다.
삭제의 경우는 `del`키워드나 `remove()`, `pop()` 메서드를 사용하면된다.
remove()와 pop()은 리스트 관련 함수 <sup> [개념 정리](#02-3-3) </sup>에서 다룬다.

### <span id="02-3-3">[3] 리스트 관련 함수</span>
문자열과 마찬가지로 리스트 변수 이름 뒤에 `.`을 붙여 여러 가지 리스트 관련 함수를 사용할 수 있다.

#### [3-1] append: 리스트에 요소 추가하기 
```python
a = [1, 2, 3]

a.append(4)
a         # [1, 2, 3, 4]

a.append([5, 6])
a         # [1, 2, 3, 4, [5, 6]]
```

#### [3-2] sort: 리스트의 정렬
```python
# 숫자의 정렬
a = [1, 4, 3, 2]
a.sort() 
a     # [1, 2, 3, 4]

# 문자의 정렬
b = ['a', 'c', 'b']
b.sort()
b     # ['a', 'b', 'c']
```

#### [3-3] reverse: 리스트 뒤집기
```python
a = ['a', 'c', 'b']
a.reverse()
a     # ['b', 'c', 'a']
```

#### [3-4] index: 인덱스 반환
```python
a = [1, 2, 3]
a.index(3)     # 2
a.index(1)     # 0
```
`index(x)` 함수는 리스트에 x값이 있다면 x의 인덱스 값(위치값)을 반환한다. 

#### [3-5] insert: 리스트에 요소 삽입
```python
a = [1, 2, 3]
a.insert(0, 4)
a    # [4, 1, 2, 3]
```
`insert(a,b)`는 리스트의 a번째 위치에 b를 삽입하는 함수이다.

#### [3-6] remove: 리스트 요소 제거
```python
a = [1, 2, 3, 1, 2, 3]
a.remove(3)
a     # [1, 2, 1, 2, 3]
```
`remove(x)`는 리스트에서 첫 번째로 나오는 x를 삭제하는 함수이다.

#### [3-7] pop: 리스트 요소 꺼내기
```python
a = [1, 2, 3]
a.pop()   # 3
a         # [1, 2]
```
`pop()`은 리스트의 맨 마지막 요소를 반환하고 그 요소는 삭제한다.

#### [3-8] count: 리스트에 포함된 요소 x의 개수 세기
```python
a = [1, 2, 3, 1]
a.count(1)   # 2
```
`count(x)`는 리스트 안에 x가 몇 개 있는지 조사하여 그 개수를 반환하는 함수이다.

#### [3-9] extend: 리스트 확장
```python
a = [1, 2, 3]
a.extend([4, 5])
a    # [1, 2, 3, 4, 5]

b = [6, 7]
a.extend(b)
a    # [1, 2, 3, 4, 5, 6, 7]
```
`extend(x)`에서 x에는 리스트만 올 수 있으며 원래의 a 리스트에 x 리스트를 더하게 된다.
`a.extend([4, 5])`는 `a += [4, 5]`와 동일하다.

## 🔥 02-4 튜플 자료형
튜플은 조금의 차이가 있을 뿐, 리스트와 유사하다. 차이는 아래와 같다.
- 리스트는 `[]`, 튜플은 `()`으로 둘러싼다.
- 리스트는 요소값의 생성, 삭제, 수정이 가능하지만 <u>튜플은 요소값을 바꿀 수 없다.</u>

### [1] 튜플의 생성 방법
```python
t1 = ()
t2 = (1,)
t3 = (1, 2, 3)
t4 = 1, 2, 3
t5 = ('a', 'b', ('ab', 'cd'))
```
튜플을 만들 때 <b>튜플이 오직 한 개의 요소값을 가질 때 요소 뒤에 `,`를 반드시 붙여줘야한다.</b>
또한 소괄호`()`를 생략하고 만들 수도 있다. 튜플은 리스트와 비슷하지만 구별해서 사용하는 것이 좋다.

튜플인 요소값을 변경할 수 없기 떄문에 프로그래밍 상에서 요소값이 변하지 않기를 원한다면 튜플을 사용하고, 요소값의 변경이 필요한 경우라면 리스트를 사용하는 것이 적절하다.

### [2] 튜플의 인덱싱과 슬라이싱, 더하기/곱하기/길이 구하기
#### (1) 튜플의 인덱싱
```python
t1 = (1, 2, 'a', 'b')
t1[0]    # 1
t1[3]    # 'b'
```
문자열, 리스트와 마찬가지로 `t1[0]`, `t1[3]`처럼 인덱싱이 가능하다.

#### (2) 튜플의 슬라이싱
```python
t1 = (1, 2, 'a', 'b')
t1[1:]   # (2, 'a', 'b')
```

#### (3) 튜플 더하기
```python
t1 = (1, 2, 'a', 'b')
t2 = (3, 4)
t3 = t1 + t2
t3 # (1, 2, 'a', 'b', 3, 4)
```

#### (4) 튜플 곱하기
```python
t2 = (3, 4)
t3 = t2 * 3
t3 # (3, 4, 3, 4, 3, 4)
```

#### (5) 튜플 길이 구하기
```python
t1 = (1, 2, 'a', 'b')
len(t1)  # 4
```

#### [참고사항]
⚠️ 튜플은 요소값을 변경할 수 없기 때문에 `sort`, `insert`, `remove`, `pop`과 같은 메서드가 없다.
사용가능한 메서드는 `count(x)`, `index(x)`, `len(t)`, `max(t)`, `min(t)`, `sum(t)` 등이 있다.

## 🔥 02-5 딕셔너리 자료형
딕셔너리는 단어 그대로 '산전'이라는 뜻이다. 즉 "people"이라는 단어에 "사람", "baseball"이라는 단어에 "야구"라는 뜻이 부합되듯이 <u>딕셔너리는 `Key`와 `Value`를 한 쌍으로 가지는 자료형</u>이다.

딕셔너리는 리스트나 튜플처럼 순차적으로 해당 요소값을 구하지 않고 `Key`를 통해 `Value`를 얻는다.
이것이 바로 딕셔너리의 가장 큰 특징이다. baseball이라는 단어의 뜻을 찾기 위해 사전의 내용을 순차적으로 모두 검색하는 것이 아니라 baseball이라는 단어가 있는 곳만 펼쳐 보는 것이다.

⚠️ 파이썬 3.7 이후에는 딕셔너리 순서가 보장된다. 즉, 딕셔너리에 아이템을 삽입한 순서가 유지되어 딕셔너리를 순회할 때 아이템이 추가된 순서대로 나온다.

### [1] 딕셔너리의 생성 방법
🌱 문법
```python
{Key1: Value1, Key2: Value2, Key3: Value3, ...}
```
딕셔너리는 `Key`와 `Value`의 쌍 여러 개가 `{}`로 둘러싸여 있다. 
각각의 요소는 `Key: Value` 형태로 이루어져 있고 쉼표(,)로 구분한다.

<br/>

🧑🏻‍💻[예제 코드]: 딕셔너리의 생성
```python
dic = {'name': 'pey', 'phone': '010-9999-1234', 'birth': '1118'}
a = {1: 'hi'}
b = {'first': [1, 2, 3]}
```
딕셔너리의 값 요소에 <u>리스트가 들어갈 수 있다.</u>

### [2] 딕셔너리 쌍 추가, 삭제하기
#### (1) 딕셔너리 쌍 추가하기
```python
a = {1: 'a'}

a[2] = 'b'
a                   # {1: 'a', 2: 'b'}

a['name'] = 'pey'
a                   # {1: 'a', 2: 'b', 'name': 'pey'}

a[3] = [1, 2, 3]
a                   # {1: 'a', 2: 'b', 'name': 'pey', 3: [1, 2, 3]}
```

#### (2) 딕셔너리 요소 삭제하기
```python
a = {1: 'a', 2: 'b', 'name': 'pey', 3: [1, 2, 3]}
del a[1]      # {2: 'b', 'name': 'pey', 3: [1, 2, 3]}
```
`del a[key]`처럼 사용하면 지정한 Key에 해당하는 `{Key: Value}` 쌍이 삭제된다.

#### [3] 딕셔너리에서 Key를 사용해 Value얻기
```python
grade = {'pey': 10, 'julliet': 99}
grade['pey']        # 10
grade['julliet']    # 99
```
딕셔너리는 Key를 사용해서 Value를 구할 수 있다.
⚠️ <u>딕셔너리 자료형 a가 있을 때 `a[1]`은 Key값 1에 대해서 찾는 것이다. 리스트 `a[1]`과는 전혀 다르다.</u>

### [4] 딕셔너리의 주의 사항
딕셔너리에서 Key는 고유한 값이므로 중복되는 Key 값을 설정하면 하나를 제외한 나머지 것들이 모두 무시된다.
또한 Key에는 리스트를 사용할 수 없다. 하지만 튜플은 key로 쓸 수 있다.
딕셔너리의 Key로 쓸 수 있느냐, 없느냐는 Key가 변하는(mutable)값인지, 변하지 않는 (immutable)값인지에 달려 있다.
리스트는 그 값이 변할 수 있기 때문에 Key로 쓸수 없다.

### [5] 딕셔너리 관련 함수
#### (1) keys(): Key 리스트 만들기
```python
a = {'name': 'pey', 'phone': '010-9999-1234', 'birth': '1118'}
a.keys()      # dict_keys(['name', 'phone', 'birth'])
```
a.keys()는 딕셔너리 a의 Key만을 모아 <b>`dict_keys 객체`를 반환</b>한다. `dict_keys`는 <u>리스트와 비슷하게 사용할 수 있는 객체로, for 문에서 바로 사용하거나 list() 함수로 리스트로 변환할 수 있다.</u>

🌱 딕셔너리 함수 `keys()`는 파이썬2 버전에서만 해도 진짜 리스트를 반환했으나, 딕셔너리가 거대할 경우, 키 복사본 리스트를 새로 만드느라 메모리를 엄청나게 낭비하는 문제가 있었다. 이를 해결하기 위해 파이썬 3부터는 메모리를 새로 쓰지 않고 원본 딕셔너리의 키들을 그대로 들여다 보는 창문(결과창)역할만 하는 `dict_keys`뷰 객체를 도입했다. 

**[dict_keys 객체의 특징]**
- 실시간 동기화 : 원본 딕셔너리의 내용이 바뀌면 `dict_keys`의 내용도 실시간으로 함께 바뀐다.
- 반복문 활용 가능: 리스트처럼 `for`문에 넣어서 곧바로 순회 가능하다.
- 리스트 메서드 사용 불가: 리스트처럼 생겼지만 내부 데이터를 조작하는 `append()`, `sort()`, `pop()`같은 리스트 전용 메서드는 사용할 수 없다.

⚠️ `dict_keys 객체`를 리스트로 반환하려면 `list(user.keys())`처럼 사용하면 되나, 이는 파이썬2에서 발생하던 리소스 낭비가 똑같이 발생하게 된다.

#### (2) values(): Value 리스트 만들기
```python
a = {'name': 'pey', 'phone': '010-9999-1234', 'birth': '1118'}
a.values()        # dict_values(['pey', '010-9999-1234', '1118'])
```
Key를 얻는 것과 마찬가지 방법으로 Value만 얻고 싶다면 values 함수를 사용하면 된다. values 함수를 호출하면 `dict_values 객체`를 반환한다.

#### (3) items(): Key, Value 쌍 얻기
```python
a = {'name': 'pey', 'phone': '010-9999-1234', 'birth': '1118'}
a.items()      # dict_items([('name', 'pey'), ('phone', '010-9999-1234'), ('birth', '1118')])
```
items 함수는 Key와 Value의 쌍을 튜플로 묶은 값을 `dict_items 객체`로 반환한다.

#### (4) clear(): Key:Value 쌍 모두 지우기
```python
a = {'name': 'pey', 'phone': '010-9999-1234', 'birth': '1118'}
a         # {}
```
clear 함수는 딕셔너리 안의 모든 요소를 삭제한다.

#### (5) get(x): Key로 Value 얻기
```python
a = {'name': 'pey', 'phone': '010-9999-1234', 'birth': '1118'}
a.get('name')     # pey
a.get('phone')    # '010-9999-1234'
```
`get(x)`함수는 x라는 Key에 대응되는 Value를 반환한다.

`a.get('name')`은 `a['name']`을 사용했을 때와 동일한 결과값을 반환한다.
다만 `a['nokey']`처럼 딕셔너리에 존재하지 않는 키로 값을 가져오려고 할 경우, `a['nokey']` 방식은 오류를 발생시키고 `a.get('nokey')` 방식은 <b>None을 반환한다는 차이가 있다.</b> Key가 반드시 존재한다고 확신할 수 있을 때는 `a[key]` 방식을, Key가 없을 수도 있을 때는 `a.get(key)` 방식을 사용하면 된다.

여기서 <b>None</b> 이란, 값이 없음을 나타내는 객체이고 조건문에서는 `False`처럼 평가된다.

<br/>

```python
a.get('nokey', '정보없음')    # 정보없음
```
딕셔너리 안에 찾으려는 Key가 없을 경우, 미리 정해 둔 디폴트 값을 대신 가져오게 하고 싶을 때는 get(x, '디폴트 값')을 사용하면 편리하다. 위의 예시에서는 딕셔너리 a에는 'nokey'에 해당하는 Key가 없다. 따라서 디폴트 값인 '정보없음'을 반환한다.

#### (6) in: 해당 Key가 딕셔너리 안에 있는지 조사하기
```python
a = {'name':'pey', 'phone':'010-9999-1234', 'birth': '1118'}
'name' in a    # True
'email' in a   # False
```

#### (7) pop(): Key로 Value꺼내기
```python
a = {'name':'pey', 'phone':'010-9999-1234', 'birth': '1118'}
phone = a.pop('phone')
phone     # '010-9999-1234'
a         # {'name': 'pey', 'birth': '1118'}
```
pop(x) 함수는 딕셔너리에서 Key가 x인 항목을 삭제한 후 그 Value를 반환한다. get 함수와 달리 pop은 해당 항목을 딕셔너리에서 삭제한다는 차이가 있다.

```python
email = a.pop('email', '정보없음')
email # 정보없음
```
존재하지 않는 Key에 대해서는 디폴트 값을 지정할 수 있다.

## 🔥 02-6 집합 자료형
