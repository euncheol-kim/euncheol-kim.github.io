### 🌱 포스팅 작성 이유

Kotlin으로 맵을 만들 때 `mapOf(1 to "one")`처럼 씁니다. 여기서 `to`가 문법 키워드처럼 보이지만, 실제로는 평범한 함수를 특별한 모양으로 호출한 것입니다. 이 호출 방식인 중위 호출을 정리합니다.

---

## 1. 중위 호출이란

**중위 호출(Infix Call)** 은 함수 이름을 **객체와 인자 사이에** 놓고, 점(`.`)과 괄호 없이 호출하는 방식입니다.

```kotlin
1.to("one")     // 일반 호출
1 to "one"      // 중위 호출
```

두 줄은 완전히 같은 코드입니다. `to`는 `Pair(1, "one")`을 만들어 돌려주는 함수일 뿐입니다.

```kotlin
val pair = 1 to "one"          // Pair(1, "one")
val (number, name) = pair      // number = 1, name = "one"
```

---

## 2. infix 함수를 만드는 조건

함수 앞에 `infix`를 붙이면 중위 호출이 가능해집니다. 표준 라이브러리의 `to`도 이렇게 선언되어 있습니다.

```kotlin
infix fun <A, B> A.to(that: B): Pair<A, B> = Pair(this, that)
```

아무 함수에나 붙일 수 있는 것은 아니고, 아래 조건을 모두 만족해야 합니다.

| 조건 | 이유 |
| --- | --- |
| 멤버 함수이거나 확장 함수 | 이름 왼쪽에 올 객체가 있어야 한다 |
| 파라미터가 정확히 1개 | 이름 오른쪽에 올 값이 하나여야 한다 |
| `vararg`가 아니고 기본값이 없다 | 오른쪽 값을 생략하거나 여러 개 줄 수 없다 |

직접 만들어 보면 다음과 같습니다.

```kotlin
infix fun Int.plus2(other: Int): Int = this + other

3 plus2 4       // 7
3.plus2(4)      // 7 — infix 함수도 일반 호출이 가능하다
```

---

## 3. 자주 만나는 infix 함수

| 함수 | 예시 | 결과 |
| --- | --- | --- |
| `to` | `1 to "one"` | `Pair(1, "one")` |
| `until` | `0 until 3` | 0, 1, 2 |
| `downTo` | `3 downTo 1` | 3, 2, 1 |
| `step` | `0..10 step 5` | 0, 5, 10 |
| `and` / `or` / `xor` | `true and false` | `false` |
| `shl` / `shr` | `1 shl 3` | 8 |

---

## 4. 주의할 점

### 4.1 우선순위

중위 호출은 **산술 연산자보다 늦게**, **비교·논리 연산자보다 먼저** 계산됩니다.

```kotlin
1 shl 2 + 3           // 1 shl (2 + 3) = 32   — (1 shl 2) + 3 이 아니다
0 until n * 2         // 0 until (n * 2)
a && b xor c          // a && (b xor c)
```

헷갈릴 때는 괄호를 쓰는 것이 안전합니다.

### 4.2 왼쪽 객체는 생략할 수 없다

클래스 안에서 자기 자신의 infix 함수를 중위 호출할 때는 `this`를 반드시 적어야 합니다.

```kotlin
class MyList {
    infix fun add(s: String) { /* ... */ }

    fun build() {
        this add "abc"      // ✅
        add("abc")          // ✅ 일반 호출
        add "abc"           // ❌ 왼쪽 객체가 없어서 컴파일 에러
    }
}
```

---

## 5. 마무리

**중위 호출은 `a.함수(b)`를 `a 함수 b`로 쓰는 표기법일 뿐입니다.** `infix`가 붙은, 파라미터가 하나인 멤버 함수나 확장 함수라면 이렇게 호출할 수 있습니다. `to`, `until`, `step`처럼 두 값의 관계를 문장처럼 읽히게 하고 싶을 때 쓰이며, 산술 연산과 섞일 때의 우선순위만 조심하면 됩니다.
