# 1. AX
- Agent-centric?
- AI 활용: 판단/조정/검증/보완
- 기업: 사고와 관련된 중요성을 강조한다. -> 문제의식을 갖춘 인재

- 기술부터 찾는다 -> 문제부터 정의한다
- 만들 줄 안다 -> 설명할 수 있다
- AI 결과를 그냥 쓴다 -> 검증한다.
- 도구를 잘 안다 -> 원리를 잘 안다.
- 직원 되기를 준비한다. -> 팀장 되기를 준비한다.
- 부분에 집착한다. -> 전체를 조망한다.
- 기술보다는 원리/원칙/태도..


- 기술은 항상 발전하고 과도기에 있다. 따라서 기술을 따라 는 것이 아닌 문제를 풀어나가는 태도가 중요하다. (문제인식 -> 사고 -> 해결 -> 다시 문제인식)
