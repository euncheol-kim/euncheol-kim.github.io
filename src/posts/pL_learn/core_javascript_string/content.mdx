## 1. 문자열
Javascript는 글자 하나만 저장할 수 있는 별도의 자료형이 없다.
텍스트 형식의 데이터는 길이에 상관없이 문자열 형태로 저장된다.
Javascript에서 문자열은 페이지 인코딩 방식과 상관없이 항상 UTF-16 형식을 따른다.

### 1-1. 템플릿 리터럴 (template literal)
🧑🏻‍💻[예제 코드] 템플릿 리터럴:
```javascript
------------------------------------------------------------
function sum(a, b) {
  return a + b;
}

// (1) 백틱을 이용해 표현식을 ${...}을 감싸 줄력하는 방법
alert(`1 + 2 = ${sum(1, 2)}.`); // 1 + 2 = 3.
------------------------------------------------------------
// (2) 여러줄을 작성하는 방법
let guestList = `손님:
1. John
2. Pete
3. Mary
`;

alert(guestList); // 손님 리스트를 여러 줄에 걸쳐 작성
------------------------------------------------------------
```
백틱은 다양한 기능을 제공하며, "템플릿 함수(template function)"에서도 사용된다.
`func'string'`같이 첫 번째 백틱 바로 앞에 함수 이름(`func)`을 써주면, 이 함수는 백틱 안의 문자열 조각이나 표현식 평가 결과를 인수로 받아 자동으로 호출한다.
이런 기능을 '태그드 템플릿(tagged template)'라고 부르는데, 태그드 템플릿을 사용하면 사용자 지정 템플릿에 맞는 문자열을 쉽게 만들 수 있다. 태그드 템플릿과 템플릿 함수에 대한 내용은 <a target="black" href="https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Template_literals#Tagged_templates">MDN 문서</a>를 참고하자
참고로 이 기능은 많이 사용되지는 않는다.

### 1-2. 특수문자
![](./special_string.png)
```javascript
let str1 = "Hello\nWorld"; // '줄 바꿈 기호'를 사용해 두 줄짜리 문자열을 만듦

// 백틱과 일반적인 줄 바꿈 방법(엔터)을 사용해 두 줄짜리 문자열을 만듦
let str2 = `Hello
World`;

alert(str1 == str2); // true
```
표의 특수문자를 이용하여 값을 만들 수도 있음을 기억한다.


### 1-3. 문자열의 길이
🧑🏻‍💻 [예제 코드]`\n`이 포함된 문자열의 길이:
```javascript
alert( `My\n`.length ); // 3
```
`\n`은 <b>'특수 문자' 하나로 취급</b> 되기 때문에 `My\n`의 길이는 3이다.

### 1-4. 특정 문자에 접근하기
🧑🏻‍💻[예제 코드] 특정 글자에 접근하는 코드 예시:
```javascript
let str = `Hello`;

// 첫 번째 글자
alert( str[0] ); // H
alert( str.charAt(0) ); // H

// 마지막 글자
alert( str[str.length - 1] ); // o
```
가장 많이 사용하는 방식은 `[]`를 사용한 방식이다. `charAt`은 하위 호환성을 위해 남겨진 메소드로 이해하면 된다.

🧑🏻‍💻[예제 코드] 접근하려는 위치에 글자가 없는 경우:
```javascript
let str = `Hello`;

alert( str[1000] ); // undefined
alert( str.charAt(1000) ); // '' (빈 문자열)
```
두 접근 방식의 차이는 반환할 글자가 없을 때 드러난다.
접근하려는 위치에 글자가 없는 경우 `[]`는 `undefined`를, `charAt`은 `빈 문자열`을 반환한다.

### 1-5. 문자열을 구성하는 글자를 대상으로 반복 작업 수행
🧑🏻‍💻[예제 코드] `for..of`를 사용한 대상 글자의 반복 작업:
```javascript
for (let char of "Hello") {
  alert(char); // H,e,l,l,o (char는 순차적으로 H, e, l, l, o가 됩니다.)
}
```
`for..of`를 사용하면 글자의 반복 작업을 할 수 있음을 기억한다.

### 1-6. 문자열의 불변성
⚠️[오류 코드] 할당된 문자열 값의 변경 오류:
```javascript
let str = 'Hi';

str[0] = 'h'; // Error: Cannot assign to read only property '0' of string 'Hi'
alert( str[0] ); // 동작하지 않는다.
```
문자열은 수정할 수 없다. 따라서 중간 글자 하나를 바꾸려고 하면 에러가 발생한다.

🧑🏻‍💻[예제 코드] 문제를 해결하는 방법:
```javascript
let str = 'Hi';

str = 'h' + str[1]; // 문자열 전체를 교체함

alert( str ); // hi
```
그렇게 중요한 내용은 아니지만, 이러한 방법이 있다는 것을 기억한다.

### 1-7. 대소문자 변경하기 -> toUpperCase, toLowerCase
🧑🏻‍💻[예제 코드]:
```javascript
alert( 'Interface'.toUpperCase() ); // INTERFACE
alert( 'Interface'.toLowerCase() ); // interface
```
`toUpperCase`는 주어진 문자열을 대문자로, `toLowerCase`는 주어진 문자열을 소문자로 바꾼다.

### 1-8. 부분 문자열 찾기 
#### [첫 번째 방법] str.indexOf(substr, position) 사용하기
🧑🏻‍💻[예제 코드]:
```javascript str = 'Widget with id';
alert( str.indexOf('Widget') ); // 0, str은 'Widget'으로 시작함
alert( str.indexOf('widget') ); // -1, indexOf는 대·소문자를 따지므로 원하는 문자열을 찾지 못함

alert( str.indexOf("id") ); // 1, "id"는 첫 번째 위치에서 발견됨 (Widget에서 id)
```
👉 indexOf('찾을문자')는 문자열 안에서 '찾을 문자'가 가장 처음 등장하는 시작 위치(인덱스 숫자)를 반환한다. 
👉 만약 문자열을 끝까지 뒤져도 찾지 못하면, 실패의 의미로 -1을 반환한다.
👉 `indexOf`의 두 번째 인자 값은 선택적으로 사용가능하며, 이를 명시하면 검색이 해당 위치부터 시작된다.

⭐️🔥 `str.indexOf("id")`의 결과값의 경우, 조금 의아할 수 있다.
`indexOf`는 <b>문자열 안에서 찾을 문자가 가장 처음 등장하는 시작 위치(인덱스 숫자)</b>를 반환한다고 했다.
따라서 `Widget ...`의 문자열의 `i`를 보고 첫 번째 인덱스 값을 반환하는 것이다.

🧑🏻‍💻[예제 코드] 문자열 탐색하는 예시코드:
- 해결 목표: 주어진 문자열 str의 모든 소문자 as 단어 위치 찾기
```javascript
let str = 'As sly as a fox, as strong as an ox';

let target = 'as';
let pos = 0;

while(true) {
  let foundPos = str.indexOf(target, pos);
  if(foundPos === -1) break;
  
  alert(`위치: ${foundPos}에서 찾음`); // 7, 17, 27 위치에서 찾음
  pos = foundPos + 1;
}
```

- 해결 목표: 주어진 문자열 str의 모든 대소문자 상관없는 as 단어 위치 찾기
```javascript
------------------------------------------------------------------------------
// (1) toLowerCase()활용
let str = 'As sly as a fox, as strong as an ox';
let target = 'as';

let lowerStr = str.toLowerCase(); 
let lowerTarget = target.toLowerCase();

let pos = 0;

while (true) {
  let foundPos = lowerStr.indexOf(lowerTarget, pos);
  if (foundPos === -1) break;
      break; 

  alert(`위치: ${foundPos}에서 찾음`);
  
  pos = foundPos + 1;
}
------------------------------------------------------------------------------
// (2) 정규표현식(Regx)의 활용
const str = 'As sly as a fox, as strong as an ox';

// [1] 의도: 'as'라는 단어를 찾되, 대소문자를 무시(i)하고 문자열 전체에서 모두(g) 찾겠다는 정규식 패턴 정의
// 슬래시(/) 뒤에 붙은 'i'가 대소문자 무시를 지시하는 핵심 옵션.
const regex = /as/gi;

// [2] 의도: matchAll을 사용해 정규식 조건에 맞는 모든 결과를 순회하며 위치(index)를 출력합니다.
// 이전의 while문 + indexOf 조합을 완벽히 대체하는 최신 트렌드 코드입니다.
for (const match of str.matchAll(regex)) {
    console.log(`위치: ${match.index}에서 찾음 (찾은 단어: ${match[0]})`);
}
------------------------------------------------------------------------------
```
정규 표현식이 등장과 함께 `str.matchAll`문법을 사용했다.
`str.matchAll`의 경우 <a target="blanka" href="https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/matchAll"> 문서 </a>를 보면 나와있듯이 인수로는 정규 표현식을 받는다.
이를 꼭 기억하여 잘못된 프로그래밍을 하지 않게 주의하자.

⚠️[주의 코드] if문 안에서 사용되는 indexOf():
```javascript
let str = "Widget with id";

if (str.indexOf("Widget")) {
    alert("찾았다!"); // 의도한 대로 동작하지 않는다.
}
```
`str.indexOf("Widget")`은 0을 반환하는데, if문에선 0을 false로 간주하므로 alert 창이 뜨지 않는다.


🅾️ [해결 코드] if문 안에서 사용되는 indexOf():
```javascript
let str = "Widget with id";

if (str.indexOf("Widget") != -1) {
    alert("찾았다!"); // 의도한 대로 동작합니다.
}
```
따라서 부분 문자열 여부를 검사하려면 아래와 같이 -1과 비교해야한다.

#### [두 번째 방법] str.lastIndexOf(substr, position)
🧑🏻‍💻[예제 코드]:
```javascript 
let str = 'Widget with id';
alert( str.lastIndexOf('Widget') ); // 0, str은 'Widget'으로 시작함
alert( str.lastIndexOf('widget') ); // -1, indexOf는 대·소문자를 따지므로 원하는 문자열을 찾지 못함

alert( str.lastIndexOf("id") ); // 12, "id"는 첫 번째 위치에서 발견됨 (Widget에서 id)
```
우리의 눈에서는 보이지 않지만 위 스크립트가 실행되면 문자를 뒤에서부터 비교하게 된다.
`str.indexOf("id")`를 하게 될 경우 `1`이 출력되는데, `str.lastIndexOf("id")`를 하게 되면 `12`가 출력됨을 알 수 있다.

#### [세 번째 방법] 비트 NOT 연산자를 사용한 기법
```javascript
alert( ~2 ); // -3, -(2+1)과 같음
alert( ~1 ); // -2, -(1+1)과 같음
alert( ~0 ); // -1, -(0+1)과 같음
alert( ~-1 ); // 0, -(-1+1)과 같음
```
비트 NOT 연산자는 피연산자를 32비트 정수로 바꾼 후(소수부는 모두 버려짐) 모든 비트를 반전한다.
- 모든 비트 연산자 `~`, `&`, `|`는 피연자의 값을 내부적으로 32비트 정수로 강제 변환하여 계산함을 기억한다.
- 계산이 끝나고 난 이후에는 64비트로 돌려놓는다.

주석에 나와 있는 `-(n+1)`은 음수 표현 방식으로 2의 보수에 해당한다.
2의 보수는 "어떤 숫자의 비트를 모두 뒤집은 다음 1을 더하면 그 숫자가 음수가 된다."라는 원리임을 기억한다.


🧑🏻‍💻 [에제 코드] 비트 NOT 연산자의 값의 활용:
```javascript
let str = "Widget";

if (~str.indexOf("Widget")) {
  alert( '찾았다!' ); // 의도한 대로 동작합니다.
}
```
위 예시에서 본 바와 같이 부호가 있는 32비트 정수 `n` 중, `~n`을 `0`으로 만드는 경우는 `n == -1`일 때가 유일하다.
이를 응용해서 indexOf가 -1을 반환하지 않는 경우를 if ( ~str.indexOf("...") )로 검사도 가능하다.

#### [네 번째 방법] includes, startsWith, endsWith

<b>(1) includes(substr, pos)</b>
```javascript
alert( "Widget with id".includes("Widget") ); // true
alert( "Hello".includes("Bye") ); // false

alert( "Widget".includes("id") ); // true
alert( "Widget".includes("id", 3) ); // false, 세 번째 위치 이후엔 "id"가 없습니다.
```
`str.includes(substr, pos)`는 str에 부분 문자열 substr이 있는지에 따라 true나 false를 반환한다.
부분 문자열의 위치 정보는 필요하지 않고 포함 여부만 알고 싶을 때 적합한 메서드이다.
`str.includes`에도 `str.indexOf`처럼 두 번째 인수를 넘기면 해당 위치부터 부분 문자열을 검색한다.


<b> (2) startsWith, endsWith </b>
```javascript
alert( "Widget".startsWith("Wid") ); // true, "Widget"은 "Wid"로 시작합니다.
alert( "Widget".endsWith("get") ); // true, "Widget"은 "get"으로 끝납니다.
```
두 메서드 이름 그대로 문자열 str이 특정 문자열로 시작하는지(start with) 여부와 특정 문자열로 끝나는지(end with) 여부를 확인할 때 사용할 수 있다.

### ⭐️ 1-9. 부분 문자열 추출하기
이 파트에서는 `substring`, `substr`, `slice`를 알아볼 것이다.

#### (1) str.slice(start [, end])
```javascript
let str = "stringify";
alert( str.slice(0, 5) ); // 'strin', 0번째부터 5번째 위치까지(5번째 위치의 글자는 포함하지 않음)
alert( str.slice(0, 1) ); // 's', 0번째부터 1번째 위치까지(1번째 위치의 자는 포함하지 않음)

alert( str.slice(2) ); // ringify, 2번째부터 끝까지
alert( str.slice(-4, -1) ); // gif, 끝에서 4번째부터 시작해 끝에서 1번째 위치까지
alert( str.slice(-4) ); // gify, 끝에서 4번째부터 시작해 끝까지
alert( str.slice(-1) ); // y, 끝에 문자 y를 의미
```
문자열의 <font color="steelblue">start부터 end까지(end는 미포함)를 반환</font>한다. 헷갈리지 않게 "미만"이라고 기억하면 된다.
첫 번째 인자와 마지막 인자는 음수가 될 수 있는데, 음수는 문자열의 끝에서부터 시작한다고 기억하면 된다.

#### (2) str.substring(start, [, end])
```javascript
let str = "stringify";

// 동일한 부분 문자열을 반환합니다.
alert( str.substring(2, 6) ); // "ring"
alert( str.substring(6, 2) ); // "ring"

// slice를 사용하면 결과가 다릅니다.
alert( str.slice(2, 6) ); // "ring" (같음)
alert( str.slice(6, 2) ); // "" (빈 문자열)
```
start와 end 사이에 있는 문자열을 반환한다. (end는 미포함 == 미만)
`subString`은 음수 인수를 허용하지 않는다. 음수는 0으로 처리된다.

#### (3) str.substr(start [, length])
```javascript
let str = "stringify";
alert( str.substr(2, 4) ); // ring, 두 번째부터 글자 네 개
alert( str.substr(-4, 2) ); // gi, 끝에서 네 번째 위치부터 글자 두 개
```
start에서부터 시작해 length 개의 글자를 반환한다. 마지막 숫자는 "개수"를 의미한다. 이를 유의하자.

⚠️ 주의사항
`substr`은 구식 스크립트에 대응하기 위해 남겨 둔 <b>브라우저 전용 기능</b>이다. 거의 모든 곳에서 이 메서드가 동작하긴 하지만, 브라우저 이외의 호스트 환경에서는 제대로 동작하지 않을 수 있다.

### ⭐️ 1-10. 문자열 비교하기
문자열을 비교할 땐 알파벳 순서를 기준으로 글자끼리 비교가 이루어진다.
모든 문자열은 UTF-16을 사용해 인코딩되는데, UTF-16에선 모든 글자가 숫자 형식의 코드와 매칭된다.
코드로 글자를 얻거나 글자에서 연관 코드를 알아낼 수 있는 메서드는 아래와 같다.

#### (1) str.codePointAt(pos)
```javascript
alert ("A".codePointAt(0) ) // 65
alert( "z".codePointAt(0) ); // 122
alert( "Z".codePointAt(0) ); // 90

let str = "aAbB";
alert(str.codePointAt(0)) // 97
alert(str.codePointAt(1)) // 65
alert(str.codePointAt(2)) // 98
alert(str.codePointAt(3)) // 66
```

### ⭐️ 1-11. 문자열 제대로 비교하기
언어마다 문자 체계가 다르기 때문에 문자열을 ‘제대로’ 비교하는 알고리즘을 만드는 건 생각보다 간단하지 않다.
문자열을 비교하려면 일단 페이지에서 어떤 언어를 사용하고 있는지 브라우저가 알아야 한다.
다행히도 모던 브라우저 대부분이 국제화 관련 표준인 ECMA-402를 지원하는데, ECMA-402엔 언어가 다를 때 적용할 수 있는 문자열 비교 규칙과 이를 준수하는 메서드가 정의되어 있다.

#### (1) str.localeCompare(str2)
- str이 str2보다 작으면 음수를 반환한다.
- str이 str2보다 크면 양수를 반환한다.
- str과 str2이 같으면 0을 반환한다.
```javascript
alert('a'.localeCompare('A')) // -1
```
호출하면 ECMA-402에서 정의한 규칙에 따라 `str`이 `str2`보다 작은지, 같은지, 큰지를 나타내주는 정수가 반환된다. <font color="steelblue">`localeCompare`는 유니코드와 관련이 전혀 없다.</font>

그러면 `str`과 `str2`중 크고 작음의 판단 기준은 무엇이 되는 것일까? 이는 <b> 영어 사전 규칙 </b>을 따른다.
영어 사전 규칙이란, 영어권 국가의 표준 사전 규칙(기본 로케일)에서 <b>소문자를 대문자보다 앞페이지에 배치</b>한다.
그래서 출력되는 값의 의미를 정확히 파악한다면 사전에서 더 앞 페이지나, 뒷 페이지에 있다는 의미가 되어진다.

`'a'.localeCompare('A')`라고 한다면 <b>"종이 사전에서 소문자 a가 대문자 A보다 앞페이지에 나오니까, 앞에 있다는 뜻으로 -1을 반환한다."</b>로 기억하면 된다.
