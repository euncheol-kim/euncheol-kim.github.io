## 1. 컬렉션 생성 함수

### 1.1 한눈에 보기

| 컬렉션 | 읽기 전용 | 가변 (기본) | 가변 (구현체 지정) |
| --- | --- | --- | --- |
| **List** <br/> 순서 O, 중복 O | `listOf()` <br/> `emptyList()` | `mutableListOf()` | `arrayListOf()` |
| **Set** <br/> 중복 X | `setOf()` <br/> `emptySet()` | `mutableSetOf()` | `hashSetOf()` <br/> `linkedSetOf()` <br/> `sortedSetOf()` |
| **Map** <br/> Key-Value 쌍 | `mapOf()` <br/> `emptyMap()` | `mutableMapOf()` | `hashMapOf()` <br/> `linkedMapOf()` <br/> `sortedMapOf()` |

**특별한 이유가 없으면 읽기 전용으로 만들고, 수정이 필요할 때만 `mutable~Of()`를 쓴다.**

### 1.2 구현체와 순서

| 함수 | 만들어지는 구현체 | 순서 |
| --- | --- | --- |
| `mutableListOf()`, `arrayListOf()` | `ArrayList` | 넣은 순서 |
| `mutableSetOf()`, `linkedSetOf()` | `LinkedHashSet` | 넣은 순서 |
| `hashSetOf()` | `HashSet` | 보장 없음 |
| `sortedSetOf()` | `TreeSet` | 정렬된 순서 |
| `mutableMapOf()`, `linkedMapOf()` | `LinkedHashMap` | 넣은 순서 |
| `hashMapOf()` | `HashMap` | 보장 없음 |
| `sortedMapOf()` | `TreeMap` | Key로 정렬된 순서 |

### 1.3 주의사항

| 상황 | 결과 |
| --- | --- |
| `setOf()`, `mapOf()`로 만들 때 | 넣은 순서가 유지된다. 순서가 없는 것은 `hashSetOf()`, `hashMapOf()`뿐이다 |
| `sortedSetOf()`, `sortedMapOf()` 사용 | JVM에서만 쓸 수 있다 |
| `emptyList()`처럼 빈 컬렉션을 만들 때 | 타입을 알려 줘야 한다. `emptyList<String>()` |
| 읽기 전용 컬렉션을 받았을 때 | 불변이라는 보장은 없다. 아래 참고 |

**읽기 전용은 불변이 아니다.** `List`는 읽기 전용으로, 수정 메서드가 없는 타입일 뿐이다. `List` 변수가 `MutableList` 객체를 참조하고 있다면, 그 객체가 `MutableList` 쪽에서 수정될 때 `List`로 보는 내용도 함께 바뀐다.

```kotlin
import kotlin.collections.List
import kotlin.collections.MutableList

val mutable: MutableList<Int> = mutableListOf(1)
val readOnly: List<Int> = mutable    // 복사가 아니라 같은 객체를 참조한다

mutable.add(2)    // readOnly → [1, 2]
```
